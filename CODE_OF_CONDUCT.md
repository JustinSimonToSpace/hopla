# Code of conduct

Hopla is a small, friendly project about taking care of ourselves. Let's take care of each other too.

- Be kind and welcoming, especially to first-time contributors.
- Critique ideas and code, never people.
- No harassment, discrimination, or unwanted attention of any kind.
- Health topics come up here: don't give medical advice, and respect people's limits and bodies.

Maintainers may edit or remove comments, issues or contributions that break these rules, and ban repeat
offenders. To report a problem privately, contact the maintainer through GitHub.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
