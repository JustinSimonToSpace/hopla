# Name and logo

The license covers the code, not the identity of the project. **"Hopla", the Hopla icon and the
Hopla apple character are the identity of this project** and are reserved by Justin Simon.

You're welcome to:
- say that your work is based on Hopla, or that it's compatible with Hopla;
- show the name and icon when you talk about the project itself (articles, videos, reviews).

Please don't:
- publish a modified version under the name "Hopla" or with the Hopla icon — give your fork its own
  name and icon;
- use the name or icon in a way that suggests your project is the official one or is endorsed by it.

Questions? Open an issue.
